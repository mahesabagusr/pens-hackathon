# antislop audit 001 (2026-10-08)

Scope: `src/app/page.tsx`, `src/app/layout.tsx`, `src/app/globals.css`, plus code comments in `src/server/`, `src/trpc/`, `Dockerfile`, `docker-compose.yml`, `next.config.ts`.
Mode: AFTER (audit only, nothing changed). Pick numbers to fix.

## HIGH (Hard Gate)

1. **R-02** `page.tsx:42` and `page.tsx:65`: em dash in UI text (`<option>—</option>`, "None yet — follow someone..."). Use "Select a user" and a period or colon.
2. **R-25 / R-34** `globals.css:15-20`: dark mode switches on via `prefers-color-scheme`, but the page was only styled for light. Measured on `#0a0a0a`: gray-500 4.09:1, blue-600 3.77:1, red-600 4.15:1 (all FAIL 4.5:1). The `bg-black` "Add user" button is 1.06:1 against the page, so its edge disappears. Either drop the dark block or give the page dark variants.
3. **R-27** `page.tsx:13-15, 19`: no loading or error state for `users`, `following`, `suggestions`, and `follow.error` is never rendered (a failed follow is silent). An empty user list renders an empty bordered box. Suggestions shows "None yet" while still loading.
4. **R-03** `page.tsx:25-36, 54`: at 320px, `p-8` leaves 256px; the input has no `min-w-0`, so input + button can overflow. The "follow" button and the select (`py-1`) are well under the 44px tap target.
5. **R-37**: no `DESIGN.md` and the page is not labeled as a draft. Fine for a dev harness page; label it as one (or add direction) before it becomes a product page.

## MEDIUM (Purpose-Gate)

6. **R-06** `layout.tsx:6-14` + `globals.css:25`: Geist and Geist Mono are downloaded, then `body { font-family: Arial }` overrides them, so body text renders in Arial and Geist Mono is never used. Pick one on purpose and delete the other.

## LOW (Quality Locks / Craftsmanship)

7. **C-1 / R-31** `layout.tsx:16-19`: metadata is still the template's "Create Next App" / "Generated by create next app".
8. **antislop-human** `page.tsx:29-32`: email input has only a placeholder, no label; screen readers announce "email" with no context once typed into.
